# Lending Club Loan Default Prediction

An end-to-end machine-learning and deep-learning project that studies Lending Club consumer-loan records and predicts whether a loan will **not be fully paid**.

## Problem definition

The target is `not.fully.paid`:

- `0`: loan fully paid
- `1`: loan not fully paid

The positive class is the event of interest. This dataset is imbalanced, so accuracy alone is not an adequate measure of model quality. We report precision, recall, F1, ROC-AUC and PR-AUC, and tune the classification threshold on validation data only.

## Dataset

The source CSV is `Data/loan_data.csv`. The problem statement and feature descriptions are in `Problem-Statement.md`.

## Project workflow

1. **Data validation:** inspect shape, data types, missing values, duplicate rows and target distribution.
2. **EDA:** inspect target balance, loan-purpose default rates, selected numeric distributions and numeric correlations.
3. **Preprocessing:** stratified train/validation/test split; median imputation and scaling for numeric features; most-frequent imputation and one-hot encoding for categorical features. All preprocessing is fitted on training data only.
4. **Class imbalance:** use class weights during model fitting rather than judging success by accuracy.
5. **Model comparison:** Logistic Regression and Random Forest baselines are compared with a Keras feed-forward neural network.
6. **Evaluation:** tune thresholds on the validation set; evaluate the held-out test set once using precision, recall, F1, ROC-AUC, PR-AUC and confusion matrices.

## Setup (Windows PowerShell)

Use Python 3.11 if possible.

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell blocks activation, run the commands from Command Prompt using `.venv\Scripts\activate.bat`.

## Run the project

Run commands from the repository root.

**1. Generate EDA outputs**

```powershell
python -m src.eda --data Data/loan_data.csv --output reports/figures
```

**2. Train and evaluate**

```powershell
python -m src.train --data Data/loan_data.csv --output artifacts
```

Optional training controls:

```powershell
python -m src.train --epochs 60 --batch-size 128
```

The run saves the Keras model, preprocessing pipeline, baseline models, test metrics, model comparison CSV, training history and ROC/precision-recall plots in `artifacts/`.

**3. Open notebooks**

```powershell
jupyter lab
```

Open the notebooks in the `notebooks/` folder and run cells from top to bottom.

## Important interpretation notes

- A false negative is a loan predicted as fully paid when it is in fact not fully paid. A false positive is a loan flagged as not fully paid when it is fully paid. The relative cost of these errors should guide threshold selection.
- The validation set is used to choose a threshold. The test set is reserved for final evaluation.
- The supplied feature list does not include a loan issue date. Therefore, this project cannot make a genuine out-of-time/chronological test split; the stratified random split should be described as a limitation.
- Historical associations are not proof of causation. This is an educational analysis, not a production lending decision system.
- Do not report performance numbers until you have run the code on the supplied dataset.

## Reproducibility

The scripts use a fixed random seed (42). Exact results can still vary slightly across TensorFlow, hardware and library versions.
